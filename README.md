# FastdoCodeLab

## Workspaces

- `backend/` — C# only. Open `backend/Fastdo.CodeLab.sln`; it contains `CodeLab.Server`, `CodeLab.Runner`, and tests.
- `frontend/` — React/Vite only. It is intentionally not included in the C# solution. Run `npm install` and `npm run dev` here.

`archive/legacy-scaffold/` is a preserved backup and is not an active workspace.
